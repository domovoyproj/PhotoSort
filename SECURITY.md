# Сообщения о проблемах

Не добавляйте токены, личные фотографии и локальный индекс в публичные issues. Для сообщения об уязвимости используйте приватный security advisory репозитория, если он включён.

Приложение локальное и рассчитано на одного пользователя. Не выставляйте HTTP-сервер в сеть и не запускайте его за публичным прокси. Корзина сохраняет файлы до ручного восстановления; приложение не содержит функции необратимого удаления.

# PhotoSort 0.2

Настольное приложение для Windows с ядром на Rust. Разбирает большие локальные фотобиблиотеки: точные дубли, похожие кадры, серии, быстрый выбор лучших, сравнение с синхронным зумом, избранное, экспорт и восстанавливаемая корзина. Светлый, тёмный и системный монохромные режимы.

## Запуск

Установите `PhotoSort-Setup-0.2.0-windows-x64.exe` или распакуйте portable-архив целиком и запустите `PhotoSort.exe`. Требуется Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Установщик добавляет WebView2 при отсутствии (для загрузки Runtime нужен интернет). Для portable-комплекта предусмотрен MicrosoftEdgeWebview2Setup.exe. Python для запуска не нужен. Фотографии и анализ остаются на устройстве.

Для разработки нужен Rust и Windows C++ toolchain:

```powershell
./packaging/prepare-runtime.ps1
cargo run --release
# Браузерная проверка на отдельной тестовой библиотеке:
cargo run -- --browser --port 18766 --data .photosort/dev
```

На текущем компьютере без Visual Studio используется установленный в `.photosort/tools/mingw/mingw64/bin` GNU toolchain и `cargo +stable-x86_64-pc-windows-gnu`. Каталог `bin` должен присутствовать в PATH. `start.bat` запускает собранное приложение из `dist/PhotoSort-0.2.0`.

## Рабочий процесс

1. Добавьте папку. Файлы во вложенных папках индексируются параллельно. Пауза и продолжение работают после перезапуска благодаря очереди SQLite.
2. Откройте похожие кадры или серии и нажмите «Выбрать лучшие». Переключайте кадры стрелками, выбирайте победителя клавишей P, пропускайте группу клавишей S. Решения сохраняются. Опция «Остальные в корзину» перемещает остальные кадры выбранного набора.
3. Для сравнения отметьте два кадра. Увеличение и перемещение синхронизируются; доступны масштаб 1:1 и полный экран. В сравнении можно сразу отметить лучший кадр.
4. «Разобрать дубли» показывает сохраняемые и лишние копии, суммарный объём и защищённое избранное. Приоритет задаётся предпочтительной папкой. Перед перемещением сохраняемая копия снова проверяется по SHA-256.
5. Экспорт создаёт проверенные копии избранных или выбранных оригиналов, при желании сохраняя структуру папок. RAW+JPEG с одинаковой основой имени обрабатываются вместе.
6. Корзина физически хранит файлы в `.photosort-trash` внутри исходной папки. Восстановление не перезаписывает занятый путь. Ctrl+Z отменяет выбор, избранное и перемещения, включая действия предыдущего запуска.

В просмотре: P — оставить, X — отклонить, S — пропустить. Отклонение помечает кадр; перенос в корзину выполняется отдельно. Экспорт самостоятельных копий не входит в Ctrl+Z.

## Форматы и локальные подсказки

JPEG, PNG, WebP, TIFF, BMP читаются Rust-кодом. Полная сборка содержит ImageMagick с libheif и LibRaw для HEIC/HEIF, AVIF и RAW (CR2/CR3, NEF/NRW, ARW, DNG, RAF, RW2, ORF, PEF, SRW). Поддержка RAW зависит от модели камеры. Превью RAW ограничены 8000 пикселями по стороне; оригиналы сохраняются без изменений.

Сходство определяется несколькими визуальными отпечатками; чувствительность регулируется. Серии определяются временем EXIF с интервалом до 8 секунд внутри одной папки. Возможны ложные совпадения, особенно у однотонных фотографий. Сильная обрезка может не распознаваться.

При импорте появляются подсказки о возможном смазе и яркости. «Проверить лица» локально анализирует выбранные кадры или текущую страницу с помощью MediaPipe/WASM в Worker. Подсказка о закрытых глазах основана на оценке моргания обоих глаз. Эти оценки вспомогательные; проверьте результат визуально. Модель и декодеры загружаются при сборке, во время работы сетевые сервисы не используются.

## Данные и миграция

Данные настольной версии: `%LOCALAPPDATA%\PhotoSort`. SQLite 0.1 мигрирует с сохранением идентификаторов, избранного, путей и корзины. Закройте старый экземпляр перед обновлением. Приложение блокирует одновременное открытие одного индекса.

Кеш JPEG-превью ограничивается настройкой в МБ и восстанавливается по мере необходимости. Индекс и журнал нельзя удалять, пока в корзине есть файлы. Удаление приложения установщиком сохраняет библиотеку и фотографии. Автоматической очистки корзины и необратимого удаления нет.

Подробности алгоритмов, восстановления и ограничений: [docs/UPGRADE-0.2.md](docs/UPGRADE-0.2.md).

## Сборка и проверки

```powershell
./packaging/prepare-runtime.ps1
cargo test --locked
node --check photosort/web/app.js
node --check photosort/web/face-worker.js
.\packaging\build.ps1
```

Сборка создаёт `dist/PhotoSort-0.2.0/PhotoSort.exe`, portable ZIP, контрольные суммы и установщик при наличии Inno Setup 6. Лицензии Rust-зависимостей и комплектов декодеров входят в дистрибутив. Цифровая подпись PhotoSort пока отсутствует.

Масштабный тест на 100000 записей:

```powershell
cargo test --release metadata_benchmark_100k -- --ignored --nocapture
```

Это тест группировки метаданных и страницы библиотеки. Время полного импорта зависит от числа и разрешения снимков, форматов и диска. Python-модули 0.1 сохранены для регрессионных проверок и сравнения миграции; рабочая версия 0.2 их не запускает.

Если Windows launcher повреждён, используйте `.venv/Scripts/python.exe -m graphify`. При неверном выборе корня передайте абсолютный путь репозитория и `--out`. `graphify-out/`, библиотеки, фото, токены, `target/` и дистрибутивы исключены из Git.

Архитектура: `src/library.rs` — индекс, очередь, решения и файловые операции; `src/analysis.rs` — декодирование и отпечатки; `src/server.rs` — локальный API; `src/main.rs` — настольное окно; `photosort/web/` — интерфейс и Worker анализа лиц. GitHub Actions проверяет и собирает Windows-приложение; тег версии создаёт черновик Release.

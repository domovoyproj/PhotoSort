# PhotoSort

Настольное приложение для Windows: монохромный интерфейс в духе macOS, точные дубли, похожие кадры, серии, избранное и восстанавливаемая корзина. Фотографии не отправляются в облако. Версия 0.1.0 — предварительный выпуск.

## Запуск на Windows

Нужен Python 3.11 или новее.

```powershell
python -m pip install -r requirements.txt
python -m photosort.desktop
```

После установки зависимостей можно запускать `start.bat`. Откроется собственное окно PhotoSort. Для Windows требуется Microsoft Edge WebView2 Runtime. Для готового установщика и portable-сборки Python не нужен. Portable-архив нужно распаковать целиком, затем запустить PhotoSort.exe.

Дополнительный браузерный режим: `python -m photosort.server --port 8766`. Для остановки сервера нажмите Ctrl+C в консоли.

Нажмите «Добавить папку», выберите каталог или введите путь. Вложенные папки сканируются автоматически. Прогресс показывается в интерфейсе; сканирование можно остановить. Повторный импорт пропускает неизменённые файлы. Страницы по 80 кадров ограничивают количество загружаемых превью.

## Разбор

- **Точные дубли:** SHA-256 содержимого файла. Совпадение изображения после перекодирования не считается точным дублем.
- **Похожие кадры:** 64-битный dHash, расстояние Хэмминга до 6, близкое соотношение сторон. BK-дерево ищет представителей групп без полного перебора всех пар. Возможны ложные совпадения, особенно на однотонных снимках — проверьте кадры визуально.
- **Серии:** последовательные кадры из одной папки с интервалом до 8 секунд по EXIF. Без EXIF серия не определяется.
- **Выбор:** галочки на карточках, сравнение двух кадров, избранное, сортировка по резкости. Оценка резкости — вспомогательная эвристика, не оценка художественного качества.
- **Корзина:** физическое перемещение в `.photosort-trash` внутри импортированной папки. Выберите файлы в разделе «Корзина» и восстановите. Существующие файлы никогда не перезаписываются. Постоянного удаления и автоматической очистки нет.

Поддерживаются JPEG, PNG, WebP, TIFF (первый кадр), BMP. RAW/HEIC не поддерживаются. Символические ссылки и служебные папки пропускаются. Ошибки чтения учитываются, сканирование остальных файлов продолжается.

## Хранение и безопасность

SQLite, журнал перемещений и превью: `%LOCALAPPDATA%\PhotoSort` для настольного приложения, `.photosort/` рядом с проектом для браузерного режима. В браузерном режиме можно задать `--data путь`. Не удаляйте индекс, если в корзине остались файлы: он хранит их исходные пути. Корзина остаётся на диске между запусками, незавершённые перемещения восстанавливаются по журналу. Перед перемещением сверяется SHA-256. Операции используют атомарное создание hard link и удаление исходной ссылки; файловая система должна поддерживать hard links (например, NTFS). На неподдерживаемой файловой системе операция безопасно завершится ошибкой. Сканирование и перемещение одновременно запрещены.

## Сборка для публикации

```powershell
python -m pip install -r requirements-dev.txt
.\packaging\build.ps1
```

Результат: `dist/PhotoSort/PhotoSort.exe` и portable ZIP. При установленном Inno Setup 6 дополнительно создаётся установщик `PhotoSort-Setup-0.1.0-windows-x64.exe`. Удаление приложения установщиком сохраняет библиотеку и фотографии. Сборка не подписана цифровым сертификатом.

GitHub Actions запускает тесты и сборку. Тег `v0.1.0` создаёт черновик GitHub Release с установщиком и ZIP для проверки перед публикацией. Сторонние компоненты используются согласно собственным лицензиям; перед публичным выпуском следует выбрать лицензию проекта и при необходимости подписать Windows-сборку.

Сервер слушает только `127.0.0.1`, проверяет Host и случайный токен на изменяющих запросах. Внешних CDN, аналитики и сетевой загрузки фотографий нет. Запускайте один экземпляр на один индекс. Очень большие библиотеки требуют места для превью; группировка хранит метаданные в оперативной памяти. Масштабный нагрузочный тест на сотнях тысяч пользовательских файлов пока не проводился.

## Проверка и Graphify

```powershell
python -m unittest discover -s tests -v
python -m pip install -r requirements-dev.txt
python -m graphify extract . --code-only
python -m graphify query "Library move recover_operations"
python -m graphify affected photosort/library.py
python -m graphify god-nodes
python -m graphify explain "Library"
```

`python -m graphify` эквивалентен CLI `graphify` и обходит повреждённый launcher uv, если такой установлен. Граф находится в `graphify-out/`, каталог исключён из Git. Повторяйте extract после изменения кода.

Архитектура: `photosort/library.py` — индекс, анализ и файловые операции; `photosort/server.py` — локальный HTTP API; `photosort/web/` — интерфейс без сборки и внешних зависимостей.
